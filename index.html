Sobre o Projeto

O projeto Acessogeral foi criado com o objetivo de promover a acessibilidade digital para todos os usuários, independentemente de suas limitações físicas, visuais ou cognitivas. Buscamos um design limpo, funcional e inclusivo. Este site é resultado de um esforço pessoal para aprender e aplicar boas práticas de desenvolvimento web. Ele utiliza fontes ampliadas, contraste adequado e estrutura organizada para facilitar a navegação. Além disso, toda a estrutura foi planejada sem o uso de imagens, tornando o carregamento mais leve e acessível para diferentes dispositivos e conexões. Com isso, demonstramos que é possível criar soluções acessíveis mesmo com recursos simples. Acreditamos que a web deve ser um espaço para todos — e isso começa com cada site que construímos. Este projeto também serve como inspiração para estudantes que estão iniciando no mundo da tecnologia, mostrando que com dedicação é possível criar algo funcional e relevante.
