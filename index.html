O que é acessibilidade?

A acessibilidade na web é a prática de garantir que os sites sejam utilizáveis por pessoas com diferentes deficiências, como deficiências visuais, auditivas ou motoras.

Melhorias para sites acessíveis

Existem diversas melhorias que podemos implementar para tornar os sites mais acessíveis, como:

  • Uso de contrastes adequados
  • Uso de textos alternativos para imagens
  • Foco visível para navegação com teclado
